# 배포 화면 촬영

GitHub Pages 배포가 완료된 실제 URL에서 촬영합니다. 프로젝트 로딩과 스크롤 등장 효과가 완료된 상태를 사용하세요. Chrome 개발자 도구에서 기기 도구 모음(Ctrl+Shift+M / macOS Cmd+Shift+M)을 열어 Responsive 크기를 지정할 수 있습니다. 화면 배율은 100%로 설정합니다.

1. **desktop.png**: 라이트 모드, 1440 × 1000px. 전체 섹션을 한 번 천천히 스크롤해 등장 효과를 완료한 뒤 맨 위로 이동합니다. 개발자 도구 명령 메뉴(Ctrl+Shift+P / Cmd+Shift+P)의 `Capture full size screenshot`으로 전체 페이지를 저장합니다.
2. **mobile.png**: 라이트 모드, 375 × 812px. 메뉴 열기·닫기를 확인하고 메뉴를 닫습니다. 페이지를 끝까지 스크롤한 뒤 맨 위로 돌아가 같은 방법으로 전체 페이지를 촬영합니다. 가로 스크롤이나 텍스트 겹침이 없는지 확인합니다.
3. **dark-mode.png**: 1440 × 1000px에서 헤더의 테마 버튼으로 다크 모드를 켭니다. 새로고침해 테마 유지를 확인합니다. 전체 섹션의 등장 효과를 완료하고 맨 위에서 전체 페이지를 촬영합니다.

다운로드한 PNG를 이 폴더에 위 파일명 그대로 저장합니다. 파일을 확인한 뒤 루트 README의 제출 기록에 배포 URL을 입력하고 스크린샷 링크를 연결합니다. 현재 PNG 3개는 2026-09-23 Chrome에서 로컬 서버 화면을 촬영한 결과입니다. 데스크톱·다크 모드는 1440px, 모바일은 375px 너비의 전체 페이지이며, 실제 GitHub 저장소 2개가 표시된 상태입니다. 촬영 시 동작 줄이기 설정을 적용했습니다. GitHub Pages 배포 후에는 위 방법으로 다시 촬영해 교체하세요.

현재 PNG는 Hero 코드 카드 삭제 전의 로컬 화면입니다. 최종 제출 전에 최신 화면으로 다시 촬영해야 합니다.
