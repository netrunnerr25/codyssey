# 🎬 글로벌 대작 영화 명대사 맞추기 퀴즈 게임 (Movie Quotes Quiz)

파이썬 기반의 CLI(Command Line Interface) 대화형 퀴즈 프로그램입니다. 
유명 영화의 명대사를 듣고 해당 영화 제목이나 관련 정답을 맞추는 게임입니다.

---

## 1. 프로젝트 소개
- **주제**: 글로벌 대작 영화 명대사 맞추기 (Famous Movie Quotes Quiz)
- **선정 이유**: 아이언맨, 인터스텔라, 반지의 제왕 등 전 세계적으로 대중 인지도가 높은 영화의 명대사를 주제로 선정하여, 퀴즈를 진행하는 이용자가 직관적이고 즐겁게 참여할 수 있도록 구성했습니다.

---

## 2. 주요 기능 명세
1. **퀴즈 풀기 (Play Quiz)**
   - 등록된 영화 명대사 퀴즈를 순서대로 풀이합니다.
   - 4지 선다 선택지 중 정답 번호(1~4)를 입력하여 채점합니다.
   - 풀이 완료 후 획득 점수를 출력하며, 최고 점수 달성 시 기록을 업데이트합니다.
2. **퀴즈 추가 (Add Quiz)**
   - 사용자가 새로운 영화 명대사 문제, 선택지 4개, 정답 번호를 직접 등록할 수 있습니다.
3. **퀴즈 목록 보기 (Show Quiz List)**
   - 현재 등록되어 있는 모든 퀴즈 문제 목록을 한눈에 조회합니다.
4. **최고 점수 확인 (Show Score)**
   - 현재까지 기록된 최고 점수를 확인합니다.
5. **데이터 영속성 보장 (Data Persistence)**
   - `state.json` 파일에 퀴즈 데이터와 최고 점수를 실시간으로 저장/불러오기 합니다.

## 4. Git 커밋 컨벤션 (Commit Convention)

본 프로젝트는 일관된 커밋 이력 관리와 가독성을 위해 다음과 같은 커밋 메세지 작성 규칙을 준수합니다.

### 커밋 메시지 구조
### Type 태그 정의
| 태그 (Type) | 설명 |
| :--- | :--- |
| **Feat** | 새로운 기능 추가 (퀴즈 추가, 점수 저장, 메뉴 출력 등) |
| **Fix** | 버그 수정 및 예외 처리 (입력값 예외 handling, 강제 종료 처리 등) |
| **Docs** | 문서 수정 (README.md 작성 및 수정 등) |
| **Refactor** | 코드 리팩토링 (기능 변경 없이 코드 구조 개선, 데이터 변경) |
| **Style** | 코드 포맷팅, 주석 추가 및 변경 |
| **Chore** | 기타 수정 (설정 파일, .gitignore 추가 등) |

### 커밋 메시지 작성 예시
- `Feat: 영화 명대사 퀴즈 데이터 반영 및 state.json 영속성 로직 구축`
- `Fix: 공통 입력 예외 처리 및 Ctrl+C 강제 종료 핸들링 강화`
- `Docs: README.md 실행 방법, 기능 목록 및 커밋 컨벤션 명세 작성`
- `Refactor: 퀴즈 주제를 글로벌 대작 영화 명대사로 변경`

```bash
python main.py
