# 🎯 파이썬 터미널 퀴즈 게임 (Console Quiz Game)

## 1. 프로젝트 개요
Python 기본 문법과 객체지향 개념(OOP)을 활용하여 터미널 환경에서 실행되는 콘솔 기반 퀴즈 게임입니다.  
퀴즈 풀기, 새로운 퀴즈 추가, 목록 조회, 최고 점수 기록 등의 기능을 제공하며, JSON 파일을 활용해 프로그램 재실행 시에도 데이터가 유지되는 영속성을 보장합니다.

## 2. 퀴즈 주제 및 선정 이유
- **주제**: 글로벌 대작 영화 명대사 맞추기 (Famous Movie Quotes Quiz)
- **선정 이유**: 아이언맨, 인터스텔라, 반지의 제왕 등 전 세계적으로 대중 인지도가 높은 영화의 명대사를 주제로 선정하여, 퀴즈를 진행하는 이용자가 직관적이고 즐겁게 참여할 수 있도록 구성했습니다.

## 3. 실행 방법
### 필수 개발 환경
- Python 3.10 이상

### 실행 명령
터미널에서 프로젝트 루트 디렉터리로 이동한 후 다음 명령어를 실행합니다.
```bash
python main.py
